# Отличник? Докажи!

**«Отличник? Докажи!»** — браузерная викторина на Unity, посвящённая проверке знаний по школьной программе.

Игроку предлагается отвечать на вопросы из различных предметных областей, зарабатывая очки за завершённые главы, а также открывая следующий уровень сложности для этой главы.
Полученные очки можно тратить на открытие новых глав.

## Особенности

* Викторина на знание школьной программы
* Различные категории и наборы вопросов
* Система подсчёта результатов
* Интерактивный интерфейс с анимациями
* WebGL-сборка для запуска в браузере
* Интеграция игрового SDK через PluginYG

## Технологии

* **Unity**
* **C#**
* **R3**
* **UniTask**
* **UnityTweens** (аналог DOTween)
* **NaughtyAttributes**
* **PluginYG**
